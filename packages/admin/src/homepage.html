About Paradise

Paradise is a free, open-source revival of UberStrike. The proprietary Photon server SDK has been replaced with free transport shims, so anyone can host — no licence, no concurrent-user cap. The whole stack (realtime servers, web services, admin dashboard, store) runs on Docker across Windows, Linux and macOS.

You keep your XP, level and stats across matches, add friends, join clans, and chat in the lobby. The client auto-updates, so fixes reach you automatically.

Latest updates

  • Clans, mail & friends — invites, clan tags in chat, leaving clans, and a fixed mailbox (+ admin system mail).
  • Progression saved — XP, level and stats now persist after every match.
  • Connectivity — realtime now connects reliably (IPv4 transport), and the shop/credits pages no longer freeze.
  • Auto-updates — Stable & Beta channels; your client updates itself on launch.
